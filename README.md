# My Advanced Programming University Project in Python
# WorldCupSimulator
## هدف کلی پروژه

طراحی و پیاده‌سازی یک برنامه شبیه‌ساز جام جهانی فوتبال (با حضور ۳۲ تیم) با استفاده از اصول برنامه‌نویسی شیءگرا، به‌گونه‌ای که قابلیت‌های زیر را داشته باشد:

- اطلاعات تیم‌ها را از یک فایل CSV بخواند.
- قرعه‌کشی گروه‌ها را بر اساس سیدبندی و رتبه‌بندی فیفا انجام دهد. ابتدا تیم‌ها بر اساس رتبه‌بندی به چهار سید تقسیم می‌شوند. سپس تیم‌های هر سید به‌صورت تصادفی بین هشت گروه توزیع می‌شوند؛ به‌طوری‌که هر گروه دقیقاً یک تیم از هر سید داشته باشد.
- مرحله گروهی و مراحل حذفی شامل یک‌هشتم نهایی، یک‌چهارم نهایی، نیمه‌نهایی و فینال را شبیه‌سازی کند.
- قهرمان مسابقات را مشخص کند.
- شبیه‌سازی‌های متعددی (۱۰۰۰ بار) انجام دهد و درصد احتمال قهرمانی هر تیم را گزارش کند.
- براکت مراحل حذفی را به‌صورت متنی نمایش دهد.

## داستان پروژه

شما در نقش یک تحلیلگر داده‌های فوتبال قرار دارید و می‌خواهید پیش از آغاز جام جهانی ۲۰۲۶، شانس قهرمانی تیم‌های مختلف را بر اساس قدرت واقعی آن‌ها، شامل امتیاز حمله، امتیاز دفاع و رتبه‌بندی فیفا، پیش‌بینی کنید.

برای این منظور، یک شبیه‌ساز طراحی می‌کنید که مسابقات را هزاران بار اجرا کرده و نتایج آماری هر تیم را ارائه دهد. همچنین، قوانین واقعی فیفا، از جمله سیستم امتیازدهی، تفاضل گل، معیارهای شکستن تساوی و ضربات پنالتی را در شبیه‌ساز پیاده‌سازی می‌کنید.
